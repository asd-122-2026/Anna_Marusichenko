Контрольні питання¶

  1. Платформа Anaconda є базовим стандартом курсу для зручного керування науковими пакетами.

  2. Окреме середовище потрібне кожному проєкту для уникнення конфліктів між версіями пакетів.

  3. Базове оточення є загальним і глобальним, а проєктне — чистим і налаштованим під конкретну роботу.

  4. Текстовий файл використовують для точного фіксування та відновлення всіх бібліотек оточення.

  5. Шлях до інтерпретатора визначають командою where python або кодом import sys; print(sys.executable).
